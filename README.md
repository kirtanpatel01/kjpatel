# Kirtan Patel

This repository contains the personal website and portfolio for Kirtan Patel, built with Next.js and designed to showcase work, experience, blog content, and interactive experiments.

## Overview

The site is a modern portfolio experience with:

- a landing page highlighting engineering focus and background
- sections for skills, work, and experience
- blog pages for sharing ideas and updates
- responsive UI with light/dark theme support
- GitHub contribution integration and Vercel analytics

## Tech Stack

- Next.js 15 (App Router)
- React 19 and TypeScript
- Tailwind CSS
- Radix UI and custom UI primitives
- Motion for animations
- Biome for linting and formatting

## Project Structure

- app/ — routes, metadata, and page entry points
- components/ — UI, sections, labs, and reusable blocks
- lib/ — helpers, constants, and content utilities
- public/ — static assets and sound files

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000 to view the site locally.

## Useful Scripts

```bash
npm run build
npm run lint
npm run format
```

## Deployment

This project is well suited for deployment on Vercel, but it can also be hosted on any platform that supports Next.js applications.
